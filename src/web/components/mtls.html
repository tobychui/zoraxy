Mutual TLS (mTLS)

Only allow visitors that present a client certificate issued by a CA you trust

Experimental Feature

This feature is experimental and may change in future releases. Use with caution.

How it works
  1. Upload the public certificate of the CA that signed your client certificates below.
  2. Open a HTTP proxy rule, go to TLS / SSL and pick that CA under Client Certificate (mTLS).
  3. Install the client certificate (e.g. a .p12 file) on your phone or computer.
Never upload a private key here. Zoraxy only needs the CA's public certificate.

Add Client CA

Don't have a CA yet? Create one with OpenSSL
# 1. Create the CA (upload ca.crt above, keep ca.key private)
openssl req -x509 -newkey rsa:4096 -nodes -keyout ca.key -out ca.crt -days 3650 -subj "/CN=My Zoraxy Client CA"

# 2. Create a client certificate for a device
openssl req -newkey rsa:2048 -nodes -keyout client.key -out client.csr -subj "/CN=my-phone"
printf "extendedKeyUsage=clientAuth" > ext.cnf
openssl x509 -req -in client.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out client.crt -days 825 -extfile ext.cnf

# 3. Bundle it for import into a phone or browser
openssl pkcs12 -export -inkey client.key -in client.crt -certfile ca.crt -out client.p12
