Error Pages

Customize the error pages Zoraxy serves when it rejects or fails a request by itself (e.g. blocked by access rules, rate limited or upstream unreachable).
Templates are stored in the templates folder of the static web server root. Changes take effect immediately after saving.

Template Assignments

Assign a template to each situation. When set to Default, Zoraxy looks for the legacy template (e.g. whitelist.html), then the status code template (e.g. 403.html), and finally falls back to the built-in page.
