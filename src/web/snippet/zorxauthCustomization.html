Zoraxy Auth - Login Page Customization

Replace the resources used by the Zoraxy Auth login page with your own. Anything you do not customize keeps using the built-in default that ships with Zoraxy.

Text & Visibility

Shown next to the brand mark at the top left corner of the login page. Leave empty to restore the default.
Shown under the watermark icon on the panel art. Leave empty to restore the default.

How customization works

  • Uploaded resources are stored under ./conf/sso/zorxauth/branding/. Removing a file there restores the built-in default.
  • Raster images (PNG / JPG / WEBP) must keep the same width to height ratio as the resource they replace. Use the built-in scaling tool to fit any image into the correct frame.
  • SVG files are uploaded as-is because vector artwork scales to any size on its own.
  • Changes apply to new login page loads immediately, no gateway restart is needed.


Scale & Position Image

Drag the image inside the frame to reposition it. The frame is locked to the aspect ratio of the resource you are replacing, and the result is exported at the recommended resolution.
